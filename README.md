# آماده‌سازی آفلاین جزوه

Python 3.12 و وابستگی‌های requirements.txt لازم‌اند. برای اجرا روی ویندوز روی `run.bat` دوبار کلیک کنید. launcher ابتدا py -3 و سپس python را با واردکردن وابستگی‌ها بررسی می‌کند و مفسر آماده را به کار می‌گیرد. ورودی دستی لازم نیست؛ خلاصه نمایش داده می‌شود و پنجره منتظر کلید می‌ماند.

- `input/`: PDF، Word و PowerPoint خام؛ فقط خواندنی.
- `assets/`: سیلابس، تمپلیت، بوردر و فونت؛ کشف با الگوهای config.yaml.
- `samples/`: مرجع فقط خواندنی؛ `debug/`: شواهد بصری؛ `cache/`: فایل‌های میانی.
- `output/`: PDFهای قبول‌شده، گزارش فارسی UTF-8 با BOM و log.txt؛ گزارش JSON نیز برای بررسی ماشینی است.

محتوا پس از bake و حذف شماره، برداری و یکنواخت میان نوارها کوچک می‌شود؛ پس‌زمینهٔ تمام‌رنگ هم کوچک می‌شود و حاشیهٔ سفید دارد. هر فایل فقط پس از QC منتشر می‌شود. اجرای دوباره همان نام را بازنویسی می‌کند. شکست یک فایل مانع بقیه نیست؛ خروجی قدیمی آن فایل دست‌نخورده می‌ماند و موفقیت اجرای تازه محسوب نمی‌شود. خروجی‌های دارای پیشوند LessonNote_ نادیده گرفته می‌شوند.

```bat
python main.py
python main.py --input tests/data --output tests/results
python main.py --merge "input/physics_thermo_8.pdf" "input/physics_thermo_9.pdf" --namak physics_thermo_8 --output tests/merge_output
```

مسیر خروجی باید در output، cache، debug یا tests پروژه باشد. نام خروجی از نامک کانونی سیلابس و نسخهٔ config ساخته می‌شود. در ادغام، ترتیب فایل‌ها حفظ و فقط یک فرست‌پیج اضافه می‌شود.

«نامک پیدا نشد» یعنی نام فایل با سیلابس تطبیق ندارد؛ «چند منبع» یعنی الگوی assets یکتا نیست؛ «کنترل کیفیت رد شد» یعنی خروجی جدید منتشر نشده و جزئیات هر آزمون در گزارش است. جوهر زیر نوارها باید صفر باشد. تصویر کوچک پایین صفحه ممکن است هشدار شمارهٔ تصویری بدهد؛ تصویر حذف نمی‌شود. فونت یا چهار مقدار نامعتبر، PDF رمزدار و متن بلندِ جا‌نشده نیز خطای همان فایل‌اند.

برای Word/PowerPoint، LibreOffice باید در PATH یا محل معمول Program Files نصب باشد؛ در نبودش پیام «LibreOffice نصب نیست» ثبت می‌شود. تبدیل در cache و بدون تغییر اصل فایل است. نصب LibreOffice خودکار نیست.

## نصب آفلاین

روی سیستم متصل با همان ویندوز، معماری و نسخهٔ پایتون مقصد:

```bat
py -3.12 -m pip download -r requirements.txt --dest wheels
```

پوشه wheels و پروژه را به سیستم مقصد ببرید:

```bat
py -3.12 -m pip install --no-index --find-links wheels -r requirements.txt
```

پوشه wheels در گیت نادیده گرفته می‌شود. اجرای ابزار به شبکه نیاز ندارد. کد خروج CLI صفر برای موفقیت همهٔ فایل‌ها و یک برای وجود خطاست؛ خطای آرگومان‌ها کد دو دارد.
